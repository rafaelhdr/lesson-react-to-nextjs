# Four Devs Blog

A small learning project — a minimal blog built with Flask and React Vite.
Not meant for production. Just a clean example to study how a frontend and backend talk to each other.

## How to run

**Backend**

```bash
cd backend
pip install -r requirements.txt
python app.py
```

Runs on http://localhost:5000

**Frontend**

```bash
cd frontend
npm install
npm run dev
```

Runs on http://localhost:5173
